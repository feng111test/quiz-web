# Word 导入刷题

本功能是 [试卷学习工作台](../README.md) 的 Word 模式。在工作台顶部选择“Word 导入刷题”，即可在浏览器本地选择 `.docx` 解析卷，提取选择题、选项、答案和解析并开始练习。文件不上传服务器。

## 运行

在统一网页项目目录 [web/](../) 运行一次即可：

```powershell
cd web
npm install
npm run dev
```

打开终端显示的本机网址，在顶部选择“Word 导入刷题”。生产构建检查也在 `web/` 目录运行：

```powershell
npm run build
```

## 使用

1. 点击“选择本地 Word 文件”，选择 `.docx` 解析卷。
2. 等待浏览器读取正文和表格，检查左侧识别到的题目数量。
3. 选择选项并提交答案；提交后显示正确答案和 Word 中的解析。
4. 点击题目列表可跳题；“重新练习”会清除本次页面中的作答进度。

## 识别范围

- 目前识别带 A–F 选项及字母答案的选择题；多选题按完整答案组合判分。
- 填空题、解答题和缺少标准答案/选项的题目会跳过并显示题号。
- 普通段落和 Word 表格中的文字会提取；DOCX 中以浮动图片保存的公式会按原图显示在对应选项或解析下。已识别的仪器/材料表格题会保留原表格公式图并还原完整选项。未能匹配到原图的公式空位会明确标注，请核对 Word 原文；扫描页及其他复杂公式仍需人工检查。
- 仅支持新版 `.docx`，不支持旧版 `.doc`；单文件上限 50 MB。

没有文件上传接口或后端服务，导入文件、答案和练习过程不会离开本机浏览器。
